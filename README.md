# 🇨🇦 Canadian Bank Credit Risk Analysis
**Objective:** Identifying high-risk mortgage holders ahead of the 2026 "Renewal Cliff."

## 📌 Project Overview
As interest rates shift, Canadian financial institutions face increased credit risk. 
This project analyzes a simulated dataset of 50,000 borrowers to predict the **Probability of Default (PD)** based on Debt-to-Income (DTI) ratios and regional economic factors (Ontario vs. BC).

## 🛠️ Tech Stack
* **SQL:** Data cleaning and Feature Engineering (LTV & DTI calculations).
* **Python:** Predictive modeling using Logistic Regression.
* **Power BI:** Risk Heatmap and Executive Dashboard.

## 📊 Key Insights (Sneak Peek)
* **The "40% Rule":** Borrowers with a DTI over 40% are 3x more likely to default in high-rate environments.
* **Geographic Risk:** Risk is currently 12% higher in the GVA (Greater Vancouver Area) due to higher loan-to-value ratios.
